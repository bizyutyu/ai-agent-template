# example-skill: コミットメッセージ生成

これはスキルのひな形として同梱しているサンプルです。`/example-skill` で呼び出すと、
ステージング済みの変更からConventional Commits形式のコミットメッセージ案を生成します。
自分のプロジェクト用スキルを作る際のテンプレートとして、このファイルをコピーして書き換えてください。

## 手順
1. `git diff --staged` でステージング済みの差分を取得する
2. 差分の内容から変更の種類(feat/fix/docs/style/refactor/test/chore)を判定する
3. 以下の形式でコミットメッセージ案を1つ提示する:
   ```
   <type>: <変更内容を要約した一文>
   ```
4. 差分が複数の関心事にまたがる場合は、コミットを分割することを提案する
5. **勝手にコミットは実行しない**。メッセージ案を提示してユーザーの確認を待つ

## 入出力
- 入力: ステージング済みのgit差分(引数なし。呼び出し時点のリポジトリ状態を使う)
- 出力: Conventional Commits形式のメッセージ案(1〜数行)

## スキル設計原則(このサンプルが示すこと)
- **原子性**: 1スキル = 1機能(ここでは「メッセージ生成」のみ。コミット実行はしない)
- **明確な入出力**: 何を読み、何を返すかを冒頭に明記する
- **副作用の最小化**: 破壊的操作(コミット、push)は行わず、提案に留める
